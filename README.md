# 祈願觀測站 Wish Observatory 🌠

原神祈願(抽卡)追蹤工具 — 單一 HTML 檔、純前端、零依賴框架,所有資料只存在你自己的瀏覽器裡。

靈感致敬 [paimon.moe](https://paimon.moe/),但走自己的路:加入了它沒有的抽卡機率規劃器、真實機率模擬器與捕獲明光追蹤。

## 功能

### 祈願追蹤
- 角色 / 武器 / 常駐 / 集錄四池的五星保底進度環與四星保底條
- 大保底 / 小保底狀態、捕獲明光蓄能計數(連歪追蹤)
- 手動快速記錄(+1 / +10 / 出四星 / 出五星),含復原
- 鍵盤快捷鍵:`1` 一抽 · `0` 十抽 · `4` 出四星 · `5` 出五星 · `Z` 復原

### 統計分析
- 歐氣體檢:與理論分佈做蒙地卡羅比較,給出百分位與評級(歐皇~非酋)
- 五星出金時間軸、出金抽數分佈(疊加理論分佈曲線)、每月祈願次數
- 里程碑:最長乾旱、單月最狂、雙金十連、小保底連勝 / 最慘連歪
- 四星常客排行、出貨紀錄表(名稱搜尋 + 星級篩選)
- 一鍵生成「回顧卡」:可直接下載高解析度 PNG 分享(內嵌環境則截圖)

### 抽卡規劃
- 自動帶入目前保底狀態,輸入預算與目標 UP 數(1~7 隻)
- 30,000 次蒙地卡羅模擬:達成機率、50 / 90 / 99% 把握所需抽數、累積機率曲線
- 原石存抽計算:現有原石 + 每日收入 + 目標日期 → 屆時可抽數,一鍵帶入

### 抽卡模擬器
- 真實機率模型:0.6% 基礎、74 抽起軟保底遞增、90 抽必出;武器池 0.7% / 63 / 80 與命定值
- 捕獲明光簡化模型(連歪兩次後必不歪)
- 流星動畫十連,附「一直抽到出金」

### 資料
- UIGF v2.2 / v3.0 / v4.0 匯入(依 id 合併累積 — 官方刪除過期紀錄後,這裡仍保留完整歷史)
- UIGF v4 匯出、完整備份 / 還原
- 多帳號切換(各帳號資料獨立)
- 常駐五星名單可自訂(新角色進常駐池時自行加入,自動重判歪 / 沒歪)
- Google 雲端同步:備份到自己雲端硬碟的應用程式資料夾(僅該隱藏資料夾的存取權,需自備 OAuth Client ID,站內附設定教學)
- 自動匯入:`安裝自動抓取.bat` 建立每 30 分鐘的背景排程,網頁以 File System Access API 連結紀錄檔後每分鐘自動合併新紀錄,全程免動手(Chrome / Edge)

## 使用方式

直接開 `index.html` 就能用(或部署到任何靜態網頁空間)。線上版支援 **PWA**:手機瀏覽器開啟後「加入主畫面」,即可像 App 一樣離線使用。

### 匯入自己的祈願紀錄(Windows)

1. 在遊戲裡打開 **祈願 → 查看歷史紀錄**(授權 24 小時內有效)
2. 雙擊 `一鍵抓祈願紀錄.bat` — 會從遊戲快取取得查詢授權,向官方 API 抓取完整紀錄,輸出 UIGF v4 JSON
3. 到網頁的 **資料** 分頁,把 JSON 拖進去

> 授權金鑰只會傳送到米哈遊官方 API,不經過任何第三方;紀錄檔已列入 `.gitignore`,不會被提交。

想全自動:雙擊 `安裝自動抓取.bat` 建立每 30 分鐘的背景排程(`移除自動抓取.bat` 可解除),再到網頁「資料 → 自動匯入」連結紀錄檔即可。

## 技術

- 單檔 vanilla HTML / CSS / JS,無建置流程、無執行期依賴(僅 Google Fonts)
- 資料存於 `localStorage`;圖表為手刻 SVG;機率計算為蒙地卡羅與精確 PMF
- 深色星穹主題,圖表配色通過色覺辨識度驗證
